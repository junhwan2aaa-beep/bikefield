바이크필드EVERYTHING ON TWO WHEELS

오토바이 중고거래, 용품·파츠 마켓, 정비소 찾기와 단가 비교, 안심 채팅까지 한 앱에서. 왼쪽 앱은 실제로 눌러지고 채팅도 주고받을 수 있어요. 매물·상품·업체는 모두 예시예요.

01이번 버전에서 바뀐 것

안심 채팅매물·상품·정비소 어디서든 채팅이 열리고, 계좌번호나 외부 메신저 유도를 자동으로 잡아 경고해요.채팅 탭 → “z라이프” 방에서 사기 패턴 확인
마켓 (용품·파츠·부품)용품점, 파츠·튜닝 업체, 순정부품·도매 업체가 입점해서 직접 팔아요. 내 바이크 호환 필터 지원.마켓 탭 → “내 바이크 호환만” 켜기
내 차고내 바이크를 등록하면 오일 교환 시기, 호환 파츠, 정비 예약이 하나로 이어져요.홈 상단 카드

02입점 구조

유형하는 일앱에서 받는 것
센터중고 오토바이 매물 판매센터 배지, 매물 상단 노출
용품점헬멧·의류·장갑·블랙박스마켓 상점, 채팅 문의
파츠튜닝 파츠·머플러·스크린차종 호환 태그로 정확한 노출
부품순정·호환 부품, 소모품 도매정비소 B2B 주문까지 확장 가능
정비소정비·장착단가표 공개, 예약, 파츠 장착 연계

03돈 버는 구조

  • 입점 월 구독: 센터·용품점·파츠·부품업체·정비소
  • 마켓 판매 수수료: 상품 판매 금액의 일정 %
  • 안심결제 수수료: 중고 거래 금액의 일정 %
  • 파츠 구매 → 장착 예약 연계 수수료: 앱만의 고리. 파츠 사면 근처 정비소 장착까지 한 번에
  • 광고·상단 노출, 보험·할부·탁송 제휴

!시작 전에 꼭 확인할 것

  • 이륜차 압류·저당·사용신고 이력을 자동 조회할 공공 데이터나 API가 있는지. 없으면 서류 업로드 + 운영팀 검수로 시작
  • 안심결제와 마켓 결제는 PG사 에스크로 제휴가 현실적 (직접 돈을 보관하면 금융 관련 등록이 필요할 수 있음)
  • 실제 채팅은 실시간 서버(예: Firebase, Supabase 등)가 필요. 계좌번호 감지 같은 필터는 서버에서도 한 번 더 걸러야 함
  • 입점 업체 사업자 인증, 통신판매업 신고 여부 확인
